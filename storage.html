How to add a file (Google Drive)

  1. Upload the product ZIP to your Google Drive.
  2. Right-click the file → Share → set to "Anyone with the link" (Viewer) → Copy link.
  3. Paste the link below with the product name and press Save Link. The file stays private in your Drive — there is no public folder or list anyone can browse.

Give the generated link only to the buyer (after the admin approves the order). Deleting a record here removes only the record — the file stays in your Drive until you delete it there.
